# 07: 多轮编排、FDR 账本与停止条件

**What to build:** 研究循环能自动连续运行多个研究轮次。所有轮次的验证检验进入 FDR 账本累计校正；代码依据检验结果和引用情况判定有意义结论（不由 LLM 自行宣布）；下一轮基于此前所有轮次的结论和未解决问题继续深入。满足任一停止条件即停止：跑满最大轮数（默认 5）、连续 2 轮没有新的有意义结论、token 消耗达到预算。

**Blocked by:** 01

**Status:** resolved

- [x] FDR 账本跨轮次累计，每次新检验后重新校正，历史结论的校正后 p 值随之更新并在报告中体现
- [x] 有意义结论判定：验证集上 FDR 校正后显著，且有文献支持或被明确标记为文献未见
- [x] 下一轮的输入包含此前各轮有意义结论与未解决问题的汇总
- [x] 主接缝测试：三种停止条件分别触发时正确停止，并在报告中写明停止原因
- [x] token 预算耗尽时保存当前进度后停止
- [x] 探索集/验证集在多轮中保持同一划分（ADR 0003）

## Comments

- 2026-11-03 已实现并在 Mac 上调试通过。与原设计的一处差异：token 预算在每个阶段开始前检查，阶段内不打断，保证每次启动至少完成一个阶段、恢复后一定有进展；TOKEN_BUDGET 按每次启动计算。
