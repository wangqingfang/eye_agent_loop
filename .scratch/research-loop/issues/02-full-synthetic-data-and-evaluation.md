# 02: 合成数据完整版与评测章节

**What to build:** 研究者能依据数据字典生成接近首轮真实抽取规模的合成数据（默认 2 万名患者、63 个 P0 字段），其中植入共识 A 级关联、2–3 个共识未列出的新信号和一批无关字段；运行结束后报告末尾出现评测章节，展示植入信号的找回率与假信号数，用来判断研究循环是否可信。

**Blocked by:** 01

**Status:** resolved

- [x] 合成数据遵守 0/1/NA 缺失值规则，NA 与 0 在数据中可区分
- [x] 合成数据以索引日期为时间锚点，索引日期之后的信息不会出现在应只含索引日期前信息的字段里
- [x] 植入信号可通过声明配置（涉及字段、方向、强度）调整，默认包含干燥综合征 → 水液缺乏型干眼等共识 A 级关联
- [x] 植入信号清单单独保存，研究循环运行期间不可读取
- [x] 合成数据输出格式与数据契约一致：以英文变量名为列名的 CSV 或 Parquet 目录
- [x] 在合成数据上运行时，报告末尾生成评测章节（找回率、假信号数、逐条对照）；真实数据运行时不生成
- [x] 主接缝测试：植入的强信号被找回，无关字段不被报告为有意义结论

## Comments

- 2026-11-03 已实现并在 Mac 上调试通过。植入信号与无关字段定义在 src/agentloop/synthetic.py；Mac 上一次 2 万人、2 轮的离线调试运行找回 7/8 个植入信号，假信号 0。
