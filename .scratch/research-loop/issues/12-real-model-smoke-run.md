# 12: 合成数据上的真实模型冒烟运行

**What to build:** 研究者配置真实的 DeepSeek（或其他 OpenAI 兼容服务）API key，在完整合成数据上跑满一次研究循环，接入真实文献来源与 Open Targets，检查累积报告和评测章节，判断研究循环在真实模型下是否找回植入信号、结论是否合理。

**Blocked by:** 02, 03, 04, 05, 06, 07, 09

**Status:** ready-for-human

- [ ] 研究者提供 API key（通过被 git 忽略的本地配置文件或环境变量，不进入仓库）
- [ ] 在完整合成数据上跑满一次研究循环，正常停止并写明停止原因
- [ ] 评测章节中植入的共识 A 级强信号被找回
- [ ] 研究者人工审阅报告，记录结论是否合理、审稿是否过严或过松
- [ ] 记录本次运行的 token 用量，作为后续设置 token 预算的依据
