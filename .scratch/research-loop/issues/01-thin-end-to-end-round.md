# 01: 端到端打通最简研究轮次

**What to build:** 研究者用一条命令，在小规模合成数据上跑完一个完整的研究轮次（数据发现 → 文献检索 → 假设生成 → 审稿 → 登记与验证），得到一个运行目录和只有一章的 HTML 轮次报告。各部分只做最薄实现，但链路必须真实贯通：数据字典加载少量字段、合成数据植入 1 个信号、探索集/验证集一次性固定划分并对验证集做访问门控、仅 logistic 回归一个统计工具（含样本数小于 10 的分组抑制）、LLM 接口提供剧本假模型与 OpenAI 兼容客户端两种实现、外部来源接口只提供录制响应实现、五个阶段为骨架、靶点假设可登记并在验证集上检验。

**Blocked by:** None (can start immediately)

**Status:** resolved
