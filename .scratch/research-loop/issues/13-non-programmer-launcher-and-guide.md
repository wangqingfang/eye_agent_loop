## 主程序必须满足的启动契约

启动文件按下面的方式调用主程序，主程序实现时（01、07、08）必须遵守：

- 以 uv 项目形式存在于本目录，提供名为 `agentloop` 的命令入口；启动文件以 `uv run --frozen --no-dev` 调用，环境安装与机器绑定见 14 号票。
- `agentloop doctor --quick`：启动文件每次启动时调用的快速环境检查，退出码非 0 时启动文件提示修复。
- `agentloop run --synthetic --config <配置.txt 绝对路径>`：生成合成数据并开始新的研究循环。
- `agentloop run --data <数据目录绝对路径> --config <配置.txt 绝对路径>`：用真实数据开始新的研究循环。
- `agentloop resume --config <配置.txt 绝对路径>`：继续 `runs/` 下最近一次未完成的运行。
- 配置文件为 `KEY=VALUE` 纯文本，`#` 开头为注释，可能带 UTF-8 BOM 或 CRLF；键为 `API_KEY`、`BASE_URL`、`MODEL`、`MAX_ROUNDS`、`TOKEN_BUDGET`。
- 退出码 0 表示成功；非 0 表示失败，失败前须自行打印中文的可操作说明。
- 成功结束时自动在默认浏览器打开报告。
