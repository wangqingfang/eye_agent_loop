# 06: 审稿阶段

**What to build:** 在靶点假设登记之前，由一个独立的 LLM 调用专门质疑候选假设，剔除站不住的假设，以免消耗验证集。审稿意见、被剔除的假设及理由写入轮次报告，便于事后复核审稿是否过严或过松。

**Blocked by:** 01

**Status:** resolved

- [x] 审稿使用独立的 LLM 调用和独立的指令，不与假设生成共享对话上下文
- [x] 审稿只能看到候选假设、其依据的表型发现汇总和引用文献，看不到验证集任何信息
- [x] 每个候选假设得到「通过」或「剔除」结论及理由
- [x] 只有通过审稿的假设进入登记
- [x] 报告中每轮列出审稿结论、剔除理由

## Comments

- 2026-11-03 已实现并在 Mac 上调试通过。审稿使用独立的消息列表，只看到候选假设、探索集汇总和引用标题。
