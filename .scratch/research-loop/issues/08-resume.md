# 08: 断点恢复

**What to build:** 研究循环在任意阶段之后中断（进程被杀、网络失败、token 预算耗尽），研究者用同一运行目录再次启动即可从最后一个完成的阶段继续，最终运行目录和报告与不中断的运行一致。

**Blocked by:** 07

**Status:** resolved

- [x] 每个阶段完成后写检查点
- [x] 恢复时不重新划分探索集/验证集，不重复登记假设，不重复写入 FDR 账本
- [x] 主接缝测试：在每一个阶段之后模拟中断再恢复，最终产物与一次跑完的运行一致（剧本假模型与录制响应保证确定性）
- [x] 恢复时可追加 token 预算继续运行
