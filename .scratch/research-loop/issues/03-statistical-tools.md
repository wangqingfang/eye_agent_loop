# 03: 统计工具全集

**What to build:** 数据发现阶段和登记与验证阶段可以调用完整的统计工具：描述统计、分层对比、logistic 回归、Cox 回归、倾向评分匹配。每个工具以 tool schema 暴露给 LLM，只返回汇总结果（样本量、效应量、置信区间、p 值），默认调整年龄、性别、索引日期前 365 天眼科就诊次数，并在返回前抑制样本数小于 10 的分组（ADR 0001、0002）。

**Blocked by:** 01

**Status:** resolved

- [x] 每个工具的返回值中不含任何患者级记录
- [x] 默认协变量自动纳入，调用方可显式追加协变量
- [x] 样本数小于 10 的分组被抑制，并在返回值中注明「已抑制」而非静默丢弃
